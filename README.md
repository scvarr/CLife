# CLife

CLife — проект искусственной жизни, который строится с нуля вокруг переносимой модели симуляции.

Это не механический перенос старого Godot-прототипа. Старый проект используется как доказательство работоспособности отдельных идей, источник проверенных формул и будущий golden reference.

## Текущий этап

**C0 — концептуальная модель мира.**

На этом этапе production-код не пишется. Сначала определяется:

- что вообще существует в моделируемом мире;
- что представляет собой клетка;
- какие величины фундаментальны;
- какие преобразования допустимы;
- где проходит граница между симуляцией и визуализацией.

Текущие согласованные решения: [`docs/C0_CONCEPT.md`](docs/C0_CONCEPT.md).

`PROJECT_MAP.yaml` будет создан только после завершения и утверждения C0.

## Главный масштаб модели

**Клетка — атомарная активная сущность симуляции.**

CLife не моделирует внутреннюю физику клетки на уровне органелл, молекул, атомов или квантов. Клетка получает числовые входы, имеет числовые параметры и состояние, выполняет фиксированный набор преобразований и формирует числовые выходы.

```text
Inputs + Parameters + Current State
                |
                v
          Cell Functions
                |
                v
        New State + Outputs
```

## Ключевое ограничение

**Взрослая клетка не растёт.**

Геном определяет её законченный структурный состав, функции и исходные параметры в момент формирования. После формирования phenotype фиксирован.

Рост существует только на стадии зачатка/зародыша, который получает строительный материал от родительской клетки и затем формируется во взрослую клетку.

## Визуализация

Renderer не определяет законы симуляции.

Godot, Unreal Engine или другой frontend получают числовые и геометрические данные модели и строят на их основе представление.

На самом первом этапе клетка может визуализироваться простой сферой, объём которой выводится из количества структурной материи.
